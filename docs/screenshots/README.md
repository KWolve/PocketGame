## 素材生成器的产物长什么样

这个工程的绝大多数美术素材**不是画出来的，是代码生成的**（`tools/gen_icons.py` / `gen_game_art.py` / `ios_theme.py` / `gen_ha_tiles.py` …）。
上面 `A0-flipclock-assets.png` 与 `A1-icons-overview.png` 就是生成器的输出总览。
