# 输入法（`ime.ftu`）—— 自研中文全拼

> 相关代码：`src/logic/imeApp.cc`（真正的 IME）、`ui/ime.html`（键盘版面）、
> `tools/gen_ime_pinyin.py`（候选表生成器）、`tools/gen_font.py`（字库生成器）、
> `tools/ime_qa.py`（真机验收）、`tools/check_ime_candidates.py`（一致性自检）。

## 0. 一句话

本板系统内置的 IME 在 480×800 竖屏下**超出屏幕边界**，所以工程自己做了一个
`APP_TYPE_SYS_IME` 的 SysApp：**任何 ZKEditText 聚焦时框架自动拉起它**，
业务页（如 HA 的"改名"）不需要手动 `showIME()`。

## 1. 版面（面板 y=372..800，高 428；上方 372px 透明留给对话框）

| 面板内 y | 内容 |

| 98..136 | ③ 功能行：拼音缓冲回显 / 上页 / 下页 |
| 142..426 | ④ 键区：5 行 × 10 列，键 41×52，行距 58 |

★ **键区的绝对坐标是刻意不变的**（514/572/630/688/746）：中文拼音那版把面板从 424
抬到 372（上抬 52px）并加了一行功能键，键区跟着下移 52px ⇒ 用户习惯的键位一个都没动。
改这里前先算一遍绝对坐标。

★ 候选条为什么是 **5 格 × 92px**（2026-09-24 从 6 格 × 76px 改来）：见 §5。

## 2. ★ 三个"必须成对改"的上限

输入法的候选被**三层**上限层层收窄，只改一层等于没改（本次实测踩过）：

| 层 | 位置 | 现值 | 说明 |
|---|---|---|---|
| ① 字库字符集 | `tools/gen_font.py` 的 `common_chinese()` / `EXTRA_HANZI` | GB2312 全集 6763 + 63 个 GBK 人名用字 | **候选只能收字库里真有字形的字**（缺字形 = 选中后整字消失） |
| ② 候选表生成上限 | `tools/gen_ime_pinyin.py` 的 `MAX_CHARS_PER_PY` / `MAX_WORDS_PER_PY` / `MAX_WORDS` | 150 / 10 / 2500 | 每拼音最多多少单字、多少词、全表多少词 |
| ③ 运行时候选上限 | `src/logic/imeApp.cc` 的 `kMaxCand` / `kCandPerPage` | 170 / 5 | 候选总数、一层几格 |

⚠️ ② 与 ③ **必须成对改**：生成器放宽到 150、运行时还卡 60，用户看到的仍然只有 60 个候选。

⚠️ **生成顺序不能反**：`gen_font.py`（出字库）→ `gen_ime_pinyin.py`（按 cmap 过滤）。
反过来跑会用**旧字库**过滤，新加的字又被丢掉（而且不报错）。

## 3. 候选是怎么排出来的

`buildCands()`：先"精确匹配的词"（≤ `MAX_WORDS_PER_PY` 个），再"精确匹配的单字"
（≤ `MAX_CHARS_PER_PY` 个），最后**前缀匹配**（打 `ket` 也能看到 `keting` 的词）。

**顺序**（决定好不好用）：人工优先级串 `PRIORITY` → 工程文案里出现过的字 → 码点。
所以同名拼音下「室 / 灯 / 客」这类命名常用字排第 1~2 页，
而 `ZKSWE` 之类源码里出现过的字次之。

★ 二级字的坑：它们的 Unicode 码点天然比一级字大 ⇒ **不显式写进 `PRIORITY` 就永远排最后**
（`yi` 全集下 149 个字，用户要翻 30 页）。所以 `PRIORITY` 末尾专门补了人名/家居常用字。
⚠️ 别把已在 `PRIORITY` 里的字再写一遍：它用 dict 建索引，**后出现的覆盖前面的**，重复等于降权。

## 4. 真机验收（免触摸）

```bash
python tools/ime_qa.py xin --shot --serial 20080411   # 拉起输入法 + 喂拼音 + 读回候选
python tools/check_ime_candidates.py                   # 候选表 vs 当前字库的一致性
```

`ime_qa.py` 走的还是 `imeApp.cc` 自带的 QA 通道 `/tmp/pg_imecmd`（每行一条、整份内容变化才执行）：

```
k <1..45> / btn <1..45>   按键（btn 走真实控件指针 -> onClick，验 ID 映射表）
mode / mode cn / mode en  切中英 / 显式设置（脚本用显式版，免得先 dump 读一轮）
type <串>                 整串喂键；★ 行尾 ` #注释` 会被剥掉
cand <1..5> / page up|down 选候选 / 翻页
clear / del / shift / done / hide / lbl / dump
```

⚠️ **QA 通道不剥 `#` 注释**这个坑已经在 1.2.1 修掉（`type` 会先剥），
在此之前的库上写 `type keting #12` 会把 `#12` 静默输进文本。

⚠️ **拉起输入法不是"发个命令"那么简单**（`ime_qa.py` 里都处理了，这里记下来免得重踩）：
1. 固化/重启后前台是**启动器**，HA 的通道 `/tmp/pg_hacmd` 与心跳 `/tmp/pg_ha_tick.txt`
   **都不存在**（页面没跑就没有 timer）⇒ 要先 `echo 'haapp' > /tmp/pg_autostart`；
2. 切命名页是**异步**的 ⇒ 固定 `sleep` 会让下一 tap 落在 HA 主页上，症状是"dump 读不到"
   （看起来像 IME 坏了）。判据用**心跳里的 `win=N`** 轮询；
3. **屏保**（`screensaverTimeout=30`）会抢前台，屏保中 HA 的 timer 停 ⇒ QA 也不执行。

## 5. 2026-09-24：用户反馈"候选词数量太少、缺少候选字"

量出来的**真因**（都是硬数字，不是猜）：

| 现象 | 真因 | 修法 |
|---|---|---|
| 人名常用字打不出来 | 字库只裁了 GB2312 **一级** 3755 字，二级 3008 字一个都没有 ⇒ 常用人名 30 字里 **19 个打不出**（鑫/淼/婷/妍/怡/璇/瑜/瑾…） | `common_chinese()` 一级 → **全集 6763** |
| 「玥/珺/喆/垚/犇/骉」打不出来 | 这些**不在 GB2312 里**（GBK 独有） | 新增 `EXTRA_HANZI` 白名单（63 字：人名高频 + 网络用字） |
| 候选被截断 | `MAX_CHARS_PER_PY=60` 会把 `yi`(149)/`ji`(130)/`yu`(122) 砍掉一半 | → **150**（"一个字都不砍"的最小值：全集里 >150 的拼音 0 个） |
| 词组候选少 | `MAX_WORDS=1500` 砍掉 3525 条自动词；`lst[:6]` 每拼音只留 6 个词 | `MAX_WORDS` → 2500；每拼音 → 10 |
| 运行时只给 60 个候选 | `kMaxCand=60` | → **170**（150 字 + 10 词） |
| 4 字词显示不全 | 候选格 76px 放不下「客厅窗帘」（字号 20 时宽 **80px**）⇒ 实测尾巴被裁 | 候选格 **6×76 → 5×92**、字号 22（4 字 = 88px） |

**实测结果**：

| 指标 | 改前 | 改后 |
|---|---|---|
| `font/pocketgame.ttf` | 966,748 B（cmap 4209，汉字 3780） | **1,802,216 B**（cmap 7256，汉字 6826） |
| `src/logic/imePinyinData.h` | 68,959 B（词组 1489） | 112,578 B（词组 **2469**） |
| `out/update.img` | 4,309,564 B | **4,833,852 B**（分区 7,995,392，余 3,161,540） |
| 真机 `xin` | 60 个候选（无「鑫」） | **69 个候选，`鑫` 第 3 位** |
| 真机 `keting` | 6 个词 | **7 个词**，4 字词宽 85~86px < 92px **不再被裁** |
| 真机 `yue/jun/zhe` | 无「玥/珺/喆」 | 有（`珺` 第 1、`喆` 第 2、`玥` 第 3） |

固化版本：**1.2.0**（字库/候选/版面）、**1.2.1**（QA 通道剥 `#` 注释 + `mode cn|en`）。

## 6. 已知局限

- **GB2312 全集 ≠ 常用字全集**：GBK 有 2 万多字，还有一批常用字（含部分人名用字）
  不在 GB2312 里。补救办法是往 `gen_font.py` 的 `EXTRA_HANZI` 里加（会并集，重复无害），
  加之前确认基底字体 `zkswe-hans-multi.ttf` 里有该字形（没有的话出包自检会当场报错）。
- **`yi` 有 34 页**（170 个候选）。这是"一个字都不砍"的代价；常用字在前几页，
  极生僻的要翻页。若哪天嫌页多，可以调小 `MAX_CHARS_PER_PY`（同时记得改 `kMaxCand`）。
- 输入法**没有模糊音/简拼**，只支持全拼。
- `ui/ime.preview.html` 是 **9-15 的旧稿**，还没有中文拼音版与 5 格候选条 —— 需要时单独整修。
